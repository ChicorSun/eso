# ESO-BOT

## 📋介绍

Yunzai系列Bot插件,本插件基于TRSS-Yunzai作为开发环境,其他框架可能有不支持的地方

本插件主要功能是提供QQ群聊查询上古卷轴OL的相关信息

次要功能是提供轻松的娱乐功能活跃群聊气氛

## 安装插件

### 安装

#### 使用GitHub安装

```bash
git clone --depth=1 https://github.com/ChicorSun/eso.git ./plugins/eso/
```

#### 使用Gitee安装

```bash
git clone --depth=1 https://gitee.com/Chicor/eso.git ./plugins/eso/
```

### 安装依赖

```bash
pnpm install --filter=eso
```

### 使用说明

**权限说明**:
- "所有人" - 所有群成员均可使用
- "管理员" - 需要群管理员或群主权限
- "主人" - 需要在Yunzai-Bot配置文件中设置的主人账号

**图鉴查询说明**:
- `#` 开头用于查询套装图鉴
- `*` 开头用于查询技能图鉴  
- `%` 开头用于查询食物图鉴
- 支持常用别名和模糊匹配

**ESOLOG解析说明**:
- 直接发送esolog网址即可解析
- 支持排行榜和个人BD解析
- 可绑定账户生成角色名片

**TTC交易说明**:
- 支持美服和欧服查询
- 可设置默认服务器
- 价格数据定期更新

**群管理说明**:
- 全体通知功能有使用限制
- 禁言转盘需要管理员权限开启
- 投票撤回需要回复目标消息
