## 📋 介绍

**ESO-BOT** 是基于 TRSS-Yunzai 开发的《上古卷轴OL》(Elder Scrolls Online) 主题 QQ 机器人插件。

- 🎯 **主要功能**：QQ 群内查询 ESO 游戏资讯、角色图鉴、交易价格、战斗日志解析
- 🎉 **次要功能**：提供轻松的娱乐功能活跃群聊气氛
- ⚠️ 本插件基于 TRSS-Yunzai 开发环境，其他框架可能存在兼容性问题

## 📦 安装插件

### 1. 克隆插件

#### 使用 GitHub 安装

```bash
git clone --depth=1 https://github.com/ChicorSun/eso.git ./plugins/eso/
```

#### 使用 Gitee 安装

```bash
git clone --depth=1 https://gitee.com/Chicor/eso.git ./plugins/eso/
```

### 2. 安装依赖

```bash
pnpm install --filter=eso
```

### 3. 使用

发送 `#ESO帮助` 查看插件部分功能

> 💡 如需使用 `#帮助` 直接查看，请确保已安装锅巴插件，并正确为每个群配置了合适的插件黑名单或白名单

- `!` 开头查询**家具**图鉴，`!!` 开头查询**收藏品家具**图鉴
- 支持常用别名、简称和模糊匹配

### 📜 ESOLOG 解析说明

- 直接发送 esologs 网址即可解析
- 支持排行榜和个人 BD 解析
- 可绑定账户生成角色名片
- **需要先配置 ESOLogs 官方 API 凭证**（esologs.com 已启用防爬，不再支持网页抓取）：
  1. 登录 https://www.esologs.com 后在 https://www.esologs.com/api/clients/ 创建客户端应用，获取 `clientId` 和 `clientSecret`
  2. 私聊机器人发送 `#esolog设置apikey{clientId}:{clientSecret}` 完成配置（仅主人可用）
  3. 凭证保存在 `data/eso/custome_resources/config/esologcfg.json`，不会提交到 git
- 支持 `fight=last` 等非数字战斗参数（自动解析为最后一场战斗）

### 💰 TTC 交易说明

- 支持美服和欧服查询
- 可设置默认服务器
- 价格数据定期更新
- 部分功能需要配置代理才能访问

### 🎮 Steam 功能说明

- 首次使用需要配置 Steam API Key
- **本机直连 Steam API 可能被墙**：必须在 `data/eso/custome_resources/steam/config/steamConfig.json` 中配置 `proxyUrl`（格式 `https://proxy/{{url}}`），否则所有 Steam 功能不可用
- 用户需要先绑定 Steam 账户才能使用相关功能
- 在线状态推送需要开启对应推送开关
- 游戏白名单用于过滤需要监控的游戏
- 微信协议端仅支持私聊推送

### 🛠️ 群管理说明

- 全体通知功能有使用限制（23:00~7:00 静默，黑名单用户不可用）
- 禁言转盘需要管理员权限开启
- 投票撤回需要回复目标消息
- 群昵称/违规词检查需要管理员权限配置

### ⚙️ 挡位说明

- 挡位 1：极简模式（禁用 esologs 日志解析等重功能）
- 挡位 2 及以上：启用 esologs 日志解析等完整功能
- 通过 `#设置挡位 <0-5>` 调整
